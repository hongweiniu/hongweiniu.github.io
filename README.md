# hongweiniu.github.io

牛宏伟个人学术主页，适用于 GitHub Pages 用户站点。

## 访问统计

本站使用匿名访问统计。

## 本地预览

直接打开 `index.html` 即可预览。发布到 `hongweiniu.github.io` 仓库后，GitHub Pages 会自动使用根目录的 `index.html`。

## 搜索引擎

- 权威网址：`https://hongweiniu.github.io/`
- 国内镜像：`https://17hc3dd23531.vicp.fun/`
- Google、Bing 提交：`https://hongweiniu.github.io/sitemap.xml`
- 百度提交：`https://17hc3dd23531.vicp.fun/sitemap-vicp.xml`
- `robots.txt` 同时公布两个站点地图；页面的规范网址指向稳定的 GitHub Pages 站点。
- IndexNow 验证文件用于在发布后主动通知 Bing 等支持该协议的搜索引擎。

## 文件说明

- `index.html`: 页面内容与结构
- `styles.css`: 视觉样式与响应式布局
- `script.js`: 年份更新与导航高亮
- `assets/profile-niuhw.jpg`: 主页头像
- `robots.txt`: 搜索引擎抓取规则与站点地图位置
- `sitemap.xml`: GitHub Pages 权威网址的站点地图
- `sitemap-vicp.xml`: 国内镜像网址的站点地图
